# Java 16

Runnable examples of the notable language and JDK features in Java 16

The focus is on **finalized** features.

## Contents

### New in Java 16

| Folder | Feature | What it shows |
|--------|---------|---------------|
| `record/` | Records (JEP 395) | Concise way of defining an immutable data holding object |
| `pattern-matching-instanceof/` | Pattern Matching for *instanceof* (JEP 394) | Remove the need of casting after checking the instance of an object |
| `sealed-classes/` | Sealed Classes (JEP 397) | Mechanism to determine which sub-classes are allowed to extend or implement a parent class or interface |


## Running the examples

Most examples are single files:

```bash
java Example.java
```
